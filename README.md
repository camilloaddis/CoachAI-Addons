# Coach AI Add-ons

Repository di distribuzione per Home Assistant OS.

Aggiungi `https://github.com/camilloaddis/CoachAI-Addons` ai repository dello store dei componenti aggiuntivi. Installa **Coach AI Web**.

Ogni aggiornamento viene pubblicato tramite un rilascio esplicitamente approvato. Il repository contiene solo il pacchetto dell'add-on e i metadati dello store.
